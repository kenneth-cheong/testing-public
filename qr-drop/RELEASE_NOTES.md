**QR Drop** lets an iPhone send photos, videos and files to your Android phone. The iPhone scans a QR code and sends from Safari, with no app on the iPhone.

### Install (Android 11 or newer)
1. On your Android phone, download **QR-Drop.apk** below.
2. Open it. If asked, allow your browser (or WhatsApp, Files…) to install unknown apps, then tap **Install**.
3. Open **QR Drop**.

### Use it
- **Same Wi-Fi:** the iPhone scans the QR code with the Camera app, taps the link, and chooses photos or files.
- **No shared Wi-Fi:** tap **Hotspot → Start private hotspot**. The iPhone scans code 1 to join, then code 2 to send. It uses no mobile data.
- Files are saved in **Downloads › QR Drop**.

The SHA-256 of the APK is in `QR-Drop.apk.sha256`.
